## Scope: clients/subc-client ONLY.

1. **Envelope** (src/envelope.ts): 21-byte header — epoch u32 LE at [9..13], corr at [13..21], HEADER_LEN=21, PROTOCOL_VERSION=2. Admission-class bits4-5 (typed enum, default NORMAL, EXPEDITE/SHEDDABLE values), reserved mask now bits6-7. Decode rejections mirror the Rust taxonomy: class 11, SHEDDABLE outside Push/StreamData, nonzero epoch on channel 0, unsupported version.
2. **Prefix-first reader** (src/socket.ts or wherever frames are read): read/validate the 5-byte prefix (ver check) BEFORE the remaining 16 header bytes; preserve body-size cap behavior.
3. **RouteHandle** (§3.2.1, exact contract): immutable object `{ channel, epoch }` PLUS an opaque connection token (private field / object identity bound to the live socket generation). EVERY route-scoped operation (call/request, subscribe, cancel, closeRoute/closeRouteChannel, poll) takes the handle; bare-channel public APIs are REMOVED (in-place revision, no deprecation shims). Ops on a handle whose token mismatches the current connection FAIL LOCALLY with a typed error, emitting NO frame. Token changes on reconnect; managed route caches store handles; the close-beats-reopen generation guard compares full handles (your existing generation machinery likely BECOMES the token — unify rather than duplicate).
4. **Endpoint-side ingress validation** (§3.3 layer 2): maintain channel→epoch map for live routes; validate every nonzero-channel ingress frame BEFORE dispatch or lifecycle effect; mismatch/unknown → silent drop + counter. This OVERRIDES current behavior: Request, Cancel, AND Goodbye for uninstalled/mismatched slots are dropped without Error frames or callbacks (today provider.ts dispatches any nonzero Request and applies any Goodbye — that ends). In-flight request state keyed by (channel, epoch, corr).
5. **routeOpen plumb**: consume route_epoch from the RouteOpen response; install the handle into the channel→epoch map BEFORE resolving the routeOpen caller and before reading the next frame off the socket (§3.2 consumer rule). Managed-route cache stores the handle. GOODBYE eviction and unknown_channel retry keep working, now handle-keyed.
6. **Late-RouteOpen cleanup** (§3.2): a locally-timed-out route.open retains its control-op identity; if a successful RouteOpen later arrives, do NOT drop it — immediately close the returned handle with a GOODBYE (if the GOODBYE cannot be queued because egress is full/closed, close the connection). Never orphan a late-committed route.
7. **Provider side** (src/provider.ts): on_bind becomes decision-only (no route egress legal inside it); after Accept, the SDK queues the RouteBind ack (reading epoch from the RouteBind body), installs the handle, then invokes a NEW optional `onBound(handle)` callback where traffic may begin. Rejection/ack-failure: handle never installed, onBound not invoked, handler-state cleanup run directly with the tentative handle (no reliance on ingress GOODBYE). Handler state MAY install at on_bind (decision time); egress waits for onBound. Provider serve loop stamps + validates module-side epoch on all route frames.
8. **Corr hygiene** (§3.3.1): all client-minted channel-0 corrs from ONE monotonic counter, no reuse for the connection lifetime, no wrap (on exhaustion: close + reconnect). Late responses to settled corrs drop.
9. **Per-call admission class**: optional call-option (default NORMAL) stamping bits4-5 on egress frames (consumer + provider emit paths). Do not implement any shedding behavior — senders stamp, that's all.
10. **RoutePoll**: request carries route_epoch; response handling matches the echoed (route_channel, route_epoch) against the expected handle before settling/caching.
